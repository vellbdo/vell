Connaissances à compléter

Chaque connaissance que Vell ne sait pas encore guider avec un lieu sûr, rubrique par rubrique. Vous en avez obtenu une ? Votre réponse aide tous les joueurs.

Pour aider, donnez pour une connaissance de cette liste :
  • son nom exact, comme dans le jeu ;
  • où : la zone, le PNJ ou un point sur la carte (une capture d'écran aide beaucoup) ;
  • comment : dialogue, quête, monstre, objet à examiner.
Dans Vell, par la page Signaler, ou en réponse sur le forum. Pour un journal « guide attendu » : comment il s'ouvre, les quêtes dans l'ordre (qui, où, quoi faire) et quand tombe chaque connaissance.
